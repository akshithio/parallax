Work through a repository with the ChatGPT account you already have open.

Nix is a macOS workspace that holds projects, threads, tool activity, and approvals in one window. A Chrome extension you load yourself drives your signed-in ChatGPT tab, so there is no API key to paste and no second account to create.

Checking the latest release

One workspace instead of a browser tab and a terminal

Work stays grouped the way the repository is already grouped, and anything that needs a decision arrives where you are reading.

Projects stay projects

Threads belong to a repository, with their own folder, history, active state, and unread status.

Tool activity reads as work

Related commands collect beneath one activity label, and raw output stays one click away instead of filling the transcript.

Approvals interrupt once

An action that changes the workspace turns the composer into a review surface, so approving does not mean leaving the conversation.

Install once, then let it update

Three steps, and then Nix checks for new releases in the background. A downloaded update installs on the next restart, and its status stays visible in Settings.

Step 1

Move Nix into Applications

Open the DMG and drag the app across.

Step 2

Load the Chrome bridge

Unpack the ZIP, open chrome://extensions, turn on developer mode, and load the unpacked folder.

Step 3

Open a repository

Sign in to ChatGPT in that Chrome profile, pick a folder in Nix, and start a thread.

Start with the repository you have open right now

The download is the whole evaluation. Install it, point it at a folder, and see whether the workspace holds up on real work.
