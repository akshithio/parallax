Work through a repository with the ChatGPT account you already have open.

Parallax is a macOS workspace that holds projects, threads, tool activity, and approvals in one window. The Parallax Chrome extension drives your signed-in ChatGPT tab, so there is no API key to paste and no second account to create.

Checking the latest release

One workspace instead of a browser tab and a terminal

Work stays grouped the way the repository is already grouped, and anything that needs a decision arrives where you are reading.

Projects

Threads belong to a repository

Each project keeps its own folder, history, active state, and unread status instead of scrolling into one shared feed.

Tool activity

Commands read as work, not noise

Related commands collect beneath one activity label, and raw output stays one click away instead of filling the transcript.

Approvals

Review without leaving the thread

An action that changes the workspace turns the composer into a review surface, so approving does not mean switching context.

What you download

The macOS app ships through signed GitHub Releases. The browser bridge installs from the Chrome Web Store and updates through Chrome.

Install once, then let it update

Three steps, and then Parallax checks for new releases in the background. A downloaded update installs on the next restart, and its status stays visible in Settings.

Step 1

Move Parallax into Applications

Open the DMG and drag the app across.

Step 2

Install the Chrome extension

Add Parallax from the Chrome Web Store in the Chrome profile where you use ChatGPT.

Step 3

Open a repository

Sign in to ChatGPT in that Chrome profile, pick a folder in Parallax, and start a thread.

Start with the repository you have open right now

The download is the whole evaluation. Install it, point it at a folder, and see whether the workspace holds up on real work.
